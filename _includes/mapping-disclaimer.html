{%- comment -%} The notice shown on any page that displays model-to-glossary mappings. Two sentences, in the register of a published specification. It states what the mapping does not bind, and that it will change. It deliberately does not: - describe how the mappings were produced, which invites questions this release cannot answer; - say a review has not happened, which advertises a gap rather than a stage; - tell implementers not to rely on it, which undercuts the reason for publishing and is already covered by "no conformance requirement". Not "draft" and not "experimental" either: in FHIR those say the resource is unfinished and authored for testing rather than genuine use, neither of which is true. The resource carries status active and experimental false; the maturity signal is the version number, 0.x until the review settles. Kept as one include so the wording cannot drift between pages, and so that lifting it is a single edit. The same statement is carried in the ConceptMap's copyright: a tool that consumes the resource never sees this page. {%- endcomment -%} {%- assign lang = include.lang | default: page.lang | default: 'en' -%}
