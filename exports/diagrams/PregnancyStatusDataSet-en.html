Logical model for the pregnancy-status data. This is the minimal data set for the pregnancy status (consumed, for example, via Vitalink FHIR / MAGDA / VUTG / mijnburgerprofiel.be / mijngezondheid.be / caregivers).

The date the pregnancy was first registered in the system. This is not the date the pregnancy was observed, but the date it was entered in the system for the first time.

Observation conveying the current pregnancy status of the woman at the date of observation (e.g. pregnant, not pregnant). Bound to SNOMED CT, EHDS Patient Summary aligned.
