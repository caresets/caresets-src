## Added (5)

### + `CoreDataForInteroperability`

- **Display:** Core Data for Interoperability
- **Status:** active
- **EN:** set of essential health information, agreed nationally and organised by health domain, captured and exchanged in a consistent form so that any system or professional can interpret and reuse it
- **FR:** ensemble d'informations de santé essentielles, convenu au niveau national et organisé par domaine de santé, capturé et échangé sous une forme cohérente afin que tout système ou professionnel puisse les interpréter et les réutiliser
- **NL:** set essentiële gezondheidsinformatie, nationaal overeengekomen en geordend per gezondheidsdomein, die op een consistente wijze wordt vastgelegd en uitgewisseld zodat elk systeem of elke zorgprofessional deze kan interpreteren en hergebruiken

### + `FHIRResource`

- **Display:** Resource (FHIR)
- **Status:** active
- **EN:** standardised FHIR building block that structures health data and, once instantiated, carries it
- **FR:** composant de base FHIR standardisé qui structure les données de santé et, une fois instancié, les porte
- **NL:** gestandaardiseerd FHIR-bouwblok dat gezondheidsgegevens structureert en, eenmaal geïnstantieerd, deze draagt

### + `FHIRResourceInstance`

- **Display:** FHIR Resource Instance
- **Status:** active
- **EN:** health data expressed as FHIR resources conforming to Belgian profiles, in the form in which it is transported between interfaces or data actors
- **FR:** données de santé exprimées sous forme de ressources FHIR conformes aux profils belges, dans la forme sous laquelle elles sont transportées entre interfaces ou acteurs de données
- **NL:** gezondheidsgegevens uitgedrukt als FHIR-resources conform Belgische profielen, in de vorm waarin ze tussen interfaces of data-actoren worden getransporteerd

### + `BelgianProfile`

- **Display:** Belgian Profile (FHIR)
- **Status:** active
- **EN:** set of constraints on a FHIR resource that formalises the authorised and expected way to structure a data exchange in the Belgian context
- **FR:** ensemble de contraintes appliquées à une ressource FHIR qui formalise la manière autorisée et attendue de structurer un échange de données dans le contexte belge
- **NL:** set beperkingen op een FHIR-resource die de toegelaten en verwachte manier formaliseert om een gegevensuitwisseling in de Belgische context te structureren

### + `PatientFile`

- **Display:** Patient File
- **Status:** active
- **EN:** all health information held for one patient within a software package, in whatever form it is kept
- **FR:** ensemble des informations de santé conservées pour un patient au sein d'un logiciel métier, quelle que soit leur forme
- **NL:** geheel van de gezondheidsinformatie die voor één patiënt binnen een softwarepakket wordt bewaard, in welke vorm dan ook
